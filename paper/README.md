# Paper source layout

Compile `main.tex` (e.g. `../deps/install/bin/tectonic -X compile main.tex`).
Before compiling after any change in `../src`, regenerate the code references:

    python3 ../src/analysis/code_refs.py        # -> code_lines.tex, code_table.tex
    python3 ../src/analysis/plots_measured.py   # -> figures/m_*.pdf, results_macros.tex

| File | Content |
|------|---------|
| `main.tex` | Document skeleton: preamble, section inputs, bibliography, appendix |
| `preamble.tex` | Packages, compact layout, listings setup, macros (`\todo`, `\expect`, survey marks), title/author |
| `sections/00-abstract.tex` | Abstract |
| `sections/01-introduction.tex` | Introduction and contributions |
| `sections/02-related-work.tex` | Async I/O frameworks, sleep-based emulation (h5bench, async VOL, PDC, ADIOS, DLIO, POSIX), interference evidence |
| `sections/03-survey.tex` | Survey methodology, coding scheme, survey table, findings |
| `sections/04-evaluation-setup.tex` | Draft-status box, research questions, machine setup (hardware/software tables), backend implementations, async VOL patch |
| `sections/05-methodology.tex` | Compute surrogates, epoch-loop listing, workload, metrics |
| `sections/06-results.tex` | Results for RQ1-RQ4 (figures, RQ3 table) |
| `sections/07-discussion.tex` | Discussion and threats to validity |
| `sections/08-conclusions.tex` | Recommendations and conclusion |
| `sections/A-code-appendix.tex` | Code map table and full source listings |
| `refs.bib` | Bibliography (page ranges use `\pghyph`, no dashes) |
| `code_lines.tex`, `code_table.tex` | Generated by `code_refs.py`; do not edit |
| `results_macros.tex` | Generated by `plots_measured.py`; do not edit |
| `figures/` | `fig_*.pdf` placeholders, `m_*.pdf` measured |

Style rules: no em/en dashes (`---`, `--`); placeholder numbers stay in `\expect{}` until measured.

## Visual design

- `preamble.tex` defines the palette (`brand` navy, `accent` blue, `accent2` orange,
  `tint`), the title banner and full-width abstract panel (produced by the
  `abstract` environment, so `main.tex` has no `\maketitle`), sans-serif headings
  (TeX Gyre Heros), colored captions, `\summarybox{...}` and `\notebox{title}{...}`
  panels, and the running header/footer.
- `logo.tex` draws the helicopter brand mark as a TikZ pic:
  `\pic[scale=s] at (x,y) {helicopter={body}{window}{rotor}{hub}};`
- `brand/` holds standalone logo files (`helicopter_logo.{tex,pdf,png}` on a
  transparent background, `helicopter_logo_dark.*` on navy). Rebuild with
  `tectonic -X compile helicopter_logo.tex` inside `brand/`.
- Figures use TeX Gyre Heros; install the OTF files (GUST e-foundry, `qhv2.004otf.zip`)
  into `~/.local/share/fonts` and clear `~/.cache/matplotlib` before plotting.
